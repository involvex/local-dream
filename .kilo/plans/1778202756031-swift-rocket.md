# Plan: Fix build.bat for Windows

## Problem
The `build.bat` script fails on Windows with multiple errors:
1. CMake can't find toolchain file at `/data/android-ndk-r28/build/cmake/android.toolchain.cmake` (Linux path)
2. CMake can't find "Ninja" build program
3. CMAKE_C_COMPILER and CMAKE_CXX_COMPILER not set
4. CMake build cache was created with WSL and needs to be deleted

## Root Causes
1. **CMakePresets.json** uses Linux-style paths (`/data/android-ndk-r28`) for ANDROID_NDK_ROOT
2. **CMakeLists.txt** has QNN_SDK_ROOT hardcoded to Linux path (`/data/qairt/2.39.0.250926`)
3. **build.bat** doesn't set environment variables for Windows paths
4. **Build cache** contains WSL-specific configuration

## Solution

### Step 1: Delete WSL build cache
Delete `app/src/main/cpp/build/` directory to remove WSL-generated cache

### Step 2: Fix CMakePresets.json for Windows
Update the `android-base` preset to:
- Use Windows-style NDK path from environment variable or default to `C:\Users\lukas\AppData\Local\Android\Sdk\ndk\28.2.13676358`
- Use Windows host tag `windows-x86_64` (already correct in CMakeLists.txt)

### Step 3: Fix CMakeLists.txt for Windows
Update QNN_SDK_ROOT to be configurable via environment variable with default:
- Default: `D:\repos\local-dream\app\src\main\cpp\qairt`
- Allow override via `QNN_SDK_ROOT` environment variable

### Step 4: Update build.bat
Add environment variable setup before running cmake commands:
- Set `ANDROID_NDK_ROOT` to `C:\Users\lukas\AppData\Local\Android\Sdk\ndk\28.2.13676358` if not set
- Set `QNN_SDK_ROOT` to `D:\repos\local-dream\app\src\main\cpp\qairt` if not set
- Ensure ninja is on PATH (already available at `D:\msys64\mingw64\bin`)

### Step 5: Verify dependencies
- Ninja is available at `D:\msys64\mingw64\bin\ninja.exe` (already on PATH) ✓
- NDK 28.2.13676358 is available at `C:\Users\lukas\AppData\Local\Android\Sdk\ndk\28.2.13676358` ✓
- QNN SDK will be at `D:\repos\local-dream\app\src\main\cpp\qairt` (currently extracting)

## Implementation Order
1. Delete build cache
2. Update CMakePresets.json with Windows NDK path
3. Update CMakeLists.txt with configurable QNN SDK path
4. Update build.bat with environment setup
5. Test the build
